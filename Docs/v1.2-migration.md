# Migrating to OpenSceneSense Ollama 1.2

Existing analyzer construction, selectors, prompt configuration, imports, CLI video arguments, and `analyze_video()` remain supported.

## Lightweight default

The default install no longer contains the local transcription stack:

```bash
pip install openscenesense-ollama
```

Install audio explicitly:

```bash
pip install "openscenesense-ollama[audio]"
```

## Model preflight

Analysis now verifies Ollama connectivity, server version, installed models, and advertised vision capability. It never pulls a missing model. Run `openscenesense-ollama --check` before a batch job.

## Structured inference

JSON Schema enforcement is enabled by default. Use `structured_output=False` or `--no-structured-output` only for older models that cannot support it.

## Context limits

The previous unlimited `0` defaults are now bounded at 1,000 characters. Pass explicit values if an application needs different limits.

## Custom processors

A processor may return `FrameAnalysis` or a mapping with a non-empty `description`. Invalid mappings now raise `ConfigurationError`.
